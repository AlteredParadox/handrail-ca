Making a CSR

On the machine that will use the certificate, with the step CLI:

step certificate create \
  git.internal.example \
  git.csr git.key --csr \
  --san git.internal.example \
  --san 10.20.0.14 \
  --no-password --insecure

Leave the last line out to have the key encrypted with a password. Or with OpenSSL:

openssl req -new -nodes \
  -newkey ec -pkeyopt ec_paramgen_curve:P-256 \
  -keyout git.key -out git.csr \
  -subj "/CN=git.internal.example" \
  -addext "subjectAltName=DNS:git.internal.example,IP:10.20.0.14"

Paste the .csr file here. The .key file never leaves that machine.
